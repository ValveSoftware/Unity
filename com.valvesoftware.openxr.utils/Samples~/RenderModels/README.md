# Render Model Sample

This sample demonstrates how to retrieve XR controller render models from the OpenXR runtime and animate and display them.

## Usage

* Import sample from the Package Manager
* Enable the OpenXR feature in ProjectSettings -> OpenXR (Valve Utils: Render Model Sample) 
* Fix any project validation errors (will insure glTFast is installed and required shaders are preloaded).
* Build and run the example scene.
* See the RenderModelLoader MonoBehaviour in the example scene for placement details (ie: initial rotation needed)
